# Анализ результатов AB-теста
Данный репозиторий содержит анализ AB-теста, основанного на данных с Kaggle ([источник](https://www.kaggle.com/datasets/sergylog/ab-test-data/data)).

## Использованные библиотеки
- numpy 2.5.3
- pandas 3.0.6
- matplotlib 3.11.2
- seaborn 0.13.2

## Бизнес-постановка задачи
Сайт провел AB тест для того, чтобы увеличить доход (income). Необходимо провести анализ результатов и дать рекомендации.

## Описание данных
Данные содержат три столбца:
- user_id
- тип группы тестирования
- revenue

Всего в датасете содержится 10 000 записей.

*В ходе анализа данных было выявлено, что одна строка датасета соответствует одной сессии пользователя

## Описание результатов
Для получения результата AB теста была использована метрика ARPU (среднее revenue на пользователя).

---
### Нулевая и альтернативная гипотезы
$H_0$: ARPU в тесте = ARPU в контроле;

$H_1$: ARPU в тесте $\neq$ ARPU в контроле;

### Уровень значимости
$\alpha$=0.05;

### Способ принятия решения
Перцентильный доверительный интервал на основе bootstrap выборок.

---

> В ходе анализа данных эксперимента было выявлено 24% пользователей от общего количества пользователей в эксперименте, которые попали как в тестовую, так и в контрольную группу. Было принято решение исключить из анализа данные, относящиеся к таким пользователям.
>
>После исключения невалидных пользователей было получено следующие распределение количества пользователей по группам:
> - test - 2393 пользователя
> - контроль - 2390 пользователей

### Результат теста
Наблюдаемый эффект: -62% ARPU на тесте относительно контроля;

Доверительный интервал для истинного прироста ARPU теста относительно контроля (в абсолютных значениях): [-0.322, 0.004];

> Нет оснований отвергнуть нулевую гипотезу о равенстве ARPU на уровне значимости 0.05

> Эксперимент не показал статистически значимый эффект от изменения

### Замечания
В контрольной группе присутствует выброс, из-за которого дисперсия в контроле отличается от дисперсии в тестовой группе более чем в 17 раз. Выброс не был обработан, из-за чего критерий может быть недостаточно мощным для того, чтобы обнаружить реальный эффект, если он действительно есть.
